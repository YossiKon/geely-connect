# Brand assets

Icon and logo assets for the `geely_connect` integration.

Home Assistant does **not** load icons from inside a custom integration —
brand images are served from the central
[home-assistant/brands](https://github.com/home-assistant/brands) repository.

These files are kept here ready for a `home-assistant/brands` pull request:
copy them to `custom_integrations/geely_connect/` in that repo
(`icon.png` 256×256, `icon@2x.png` 512×512, `logo.png`, `logo@2x.png`).
